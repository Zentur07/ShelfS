# ShelfS

Локальная библиотечная система по ТЗ: Python, Django 5.2.19, PostgreSQL 17.11, HTML, CSS, JavaScript. Версия для защиты на этом компьютере проверена 46 тестами и полным сценарием на работающем сайте с локальной SMTP-почтой.

## Быстрый запуск для команды

Нужен **Windows x64 и Python 3.12 или 3.13**. Python скачайте с [python.org](https://www.python.org/downloads/windows/); при установке включите Python Launcher (`py`). Проверьте в новом терминале: `py -3 --version`.

1. На GitHub нажмите **Code → Download ZIP** и полностью распакуйте архив в обычную папку. Можно вместо этого клонировать репозиторий.
2. В VS Code выберите **File → Open Folder** и откройте папку, содержащую `manage.py` и `start.cmd`.
3. Откройте **Terminal → New Terminal** и выполните:

   ```powershell
   .\start.cmd
   ```

4. При первом запуске нужен интернет: установятся зависимости, PostgreSQL и локальная почта Mailpit. Дождитесь строки `ShelfS: http://127.0.0.1:8000`.
5. Откройте [сайт](http://127.0.0.1:8000) и [локальные письма](http://127.0.0.1:8025).
6. Логины и автоматически созданные пароли читателя и библиотекаря будут в `.demo-credentials.txt` **на вашем компьютере**.

Не создавайте `.env` вручную для первого запуска: программа сама подготовит настройки. Каждый участник получает свою локальную базу и свои пароли; данные между компьютерами не синхронизируются. Для запуска оставьте терминал открытым. Ctrl+C останавливает сайт; PostgreSQL и Mailpit могут продолжать работать до перезагрузки.

В репозитории находятся исходники. Python, установленная база, письма и пароли в GitHub не загружаются. Уже подготовленная локальная папка может содержать переносимый Python в `.runtime/python`; исходники с GitHub требуют установленный Python. Требуется около 1 ГБ свободного места. Docker не нужен, сервисы слушают только 127.0.0.1.

## Демонстрация

Регистрация → письмо в Mailpit → ссылка и кнопка подтверждения → вход → поиск → бронь → отмена с подтверждением → новая бронь → вход библиотекаря → выдача → возврат → история читателя. Каталог редактируется через `/admin/`, выдачи и ограничения — через `/staff/`.

Для немедленного показа напоминания назначьте дату возврата через два дня. Письмо появится в ближайший цикл, до одной минуты. В `/admin/library/notification/` видны запланированный срок, результат и попытки.

Mailpit принимает настоящие SMTP-письма локально на порту 1025, показывает на 8025 и не пересылает их во внешние ящики. Личная почта для защиты не нужна.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1 -Test
```

## Резервная копия

Из папки проекта, Python с установленными зависимостями:

```powershell
python manage.py backup_database --output data/backups/my-demo.dump
python manage.py verify_restore data/backups/my-demo.dump --database shelfs_restore_my_demo
```

Для окружения `.packages` предварительно задайте `$env:PYTHONPATH=(Resolve-Path '.packages').Path`. Архив создаётся в согласованном снимке PostgreSQL. Рядом сохраняются SHA256 архива и строк таблиц. Восстановление допускается только в НОВУЮ базу `shelfs_restore_*`, существующие базы не перезаписываются. Содержимое сверяется с исходным снимком. Проверка 6 ноября успешно сверила 20 таблиц, рабочая база сохранена.

## Правила

Начальные значения: бронь 48 часов, выдача 14 дней, напоминание за 2 дня, повтор просрочки раз в 3 дня. Настраиваются через `.env`; это решения реализации, а не числа из ТЗ. Дата возврата включительна, часовой пояс Europe/Kyiv. Повторная бронь того же названия возвращает существующую; открытая выдача этого названия запрещает новую бронь. Ограничение блокирует новые брони, сохраняя вход, историю и возможность выдачи библиотекарем вручную.

История и отзывы доступны по страницам без общего лимита. Отмена требует подтверждения. Повторное письмо возможно спустя минуту; после успешной отправки новый токен заменяет старый. Пароли хешируются, исторические связи защищены.

`.env`, `.demo-credentials.txt`, `data/`, `.packages/`, `.runtime/` не входят в архив исходников. Не публикуйте их: в `data/` находятся база, письма и резервные копии. Исходный архив при запуске создаёт новую базу, а не копирует вашу рабочую.

## Публичное размещение

Согласованный вариант — локальный. Для интернета потребуются сервер приложений, домен, HTTPS, DEBUG=0, SECRET_KEY, ALLOWED_HOSTS, публичный SITE_URL, статика, внешний SMTP и планировщик. TRUST_PROXY=1 включают только за доверенным прокси, задающим заголовок протокола. Публичное размещение, массовая нагрузка и внешняя доставка не проверялись.

SMTP и база не образуют общую транзакцию: авария после приёма письма, но до записи результата может вызвать повтор. Обычные повторы предотвращает журнал по выдаче, типу и периоду.
